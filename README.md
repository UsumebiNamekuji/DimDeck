# DimDeck

Windows 11 x64向けの、モニター別に明るさを調整するトレイ常駐ツールです。0～100％の調光を行います。

## ダウンロードと起動

1. [最新版 DimDeck v1.2.0](https://github.com/UsumebiNamekuji/DimDeck/releases/tag/v1.2.0) の **DimDeck.exe** をダウンロードします。
2. 旧DimDeck／DimmerProbeを使用中なら、トレイ右クリックの「終了」で閉じます。
3. DimDeck.exeをダブルクリックします。追加の.NETインストールは不要です。
4. 通知領域の太陽とスライダーのアイコンを左クリックすると、プライマリ画面の右下に調整画面が開きます。右クリックで「設定」「終了」を選べます。

シェブロンでスライダーを開き、カーソルを置いてホイールで調整できます。変更幅は設定から**1～9％、1％刻み**で選べます（初期値5％）。

アイコンが隠れている場合は通知領域へドラッグするか、Windowsの「設定 → 個人用設定 → タスク バー → その他のシステム トレイ アイコン」で常時表示にします。

## 全体OFF

接続中のモニターが2台以上の場合、最上段の右側に **全体OFF** が表示されます。押すと全画面の調光を一時停止し、もう一度押すと各画面の明るさと個別OFF状態へ戻ります。

停止中は個別OFF・数値・スライダー・ホイールでの変更を受け付けません。スライダーの展開・収納や設定画面は引き続き利用できます。接続が1台へ減った場合は残った画面の個別OFFへ引き継ぐので、そのOFFで再開してください。再び2台以上になっても全体OFFは自動で有効になりません。

全体OFFも前回値の復元設定に従って保存・復元します。復元を無効にすると、毎回100％で始めます。

## 設定の引き継ぎ

v1.1.1から、保存先は `%LOCALAPPDATA%\DimDeck\settings.json` です。新設定がない場合は、旧 `%LOCALAPPDATA%\DimmerProbe\settings.json` から自動で引き継ぎます。両方に設定がある場合はDimDeck側を優先します。設定の手動移動は不要です。

旧ファイルは保全のためそのまま残します。旧版へ戻す場合は旧フォルダーの設定が使われ、新版で変更した値は逆移行されません。
