# DimDeck

Windows 11 x64向けの、モニター別に明るさを調整するトレイ常駐ツールです。0～100％の調光を行います。

## ダウンロードと起動

1. [DimDeck v1.0.0](https://github.com/UsumebiNamekuji/DimDeck/releases/tag/v1.0.0) の **DimDeck.exe** をダウンロードします。
2. 旧DimmerProbeを使用中なら、トレイ右クリックの「終了」で閉じます。
3. DimDeck.exeをダブルクリックします。追加の.NETインストールは不要です。
4. 通知領域のモニター形アイコンを左クリックすると、プライマリ画面の右下に調整画面が開きます。右クリックで「設定」「終了」を選べます。

アイコンが隠れている場合は通知領域へドラッグするか、Windowsの「設定 → 個人用設定 → タスク バー → その他のシステム トレイ アイコン」で常時表示にします。

**OFF**は値を保持した一時停止、**100％**は調光なしです。シェブロンでスライダーを開き、カーソルを置いてホイールで調整できます。変更幅は設定から1／5／10％を選べます。

0％は黒表示を維持します。まず100→60→100で操作を確認し、Winキー→トレイ→100の復帰手順を把握してから試してください。設定は従来の `%LOCALAPPDATA%\DimmerProbe\settings.json` を引き継ぎます。

古い排他的フルスクリーンは非対応です。

このリポジトリは実行ファイルの配布用です。開発ソースコードは含みません。
